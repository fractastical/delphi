A hundred printed pieces, and how they go together

The kit is 100 binary STL files, one per anatomical object, all exported about a single shared origin — load them all at 0, 0, 0 and they reassemble the animal exactly. The view below does that and plays the assembly, skeleton first; the slider takes it apart again. Every number on this page is read from the kit’s own metadata by dashboard/build-print-view.mjs.
