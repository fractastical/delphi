# SEARCHES: every search and fetch made by the physics thread

All times UTC. Raw outputs are under `prior-art/raw/`; the machine log this table is built from is `prior-art/_cmdlog.txt` (one line per call, written by `search.sh` and `fetch.sh`).

## Rules applied to every row

- **run_identifier: null** for every `orx discover` call: `orx discover` prints a JSON array and issues no run identifier, so none is recorded and none was invented. Every `orx` call used `--no-telemetry` and `NCBI_EMAIL` was unset in the wrapper.
- **Privacy.** No request carries an email, name or account id. Europe PMC, Crossref, Semantic Scholar, doi.org, PubMed Central, Zenodo, Inter-Research and the Wayback Machine were plain GETs with curl's default user agent and no `email=`, `mailto=` or `tool=` parameter. Two exploratory fetches of publisher pages (Park and Choi 2010 at journals.biologists.com and Bahlman 2013 at royalsocietypublishing.org) used a generic `Mozilla/5.0` user agent at 2026-10-31T18:17:17Z; both returned 403 and are not cited as URLs.
- **OpenAlex** returned HTTP 429 (rate limited, retry after about 20,000 s) for 6 of 7 `orx discover openalex` calls and for one direct probe of api.openalex.org; the hub's prior-art run had used the same route minutes earlier. Literature discovery therefore moved to Europe PMC (REST search), with Crossref for identifier verification and Semantic Scholar for open-access locations. Every such call is logged below.
- **Candidate DOIs recalled from memory were not trusted.** Each was resolved against Crossref and kept only when the returned title matched; `10.1242/jeb.203.1.105` (a guess for an unrelated paper) returned 404 and is not cited anywhere.
- Publisher PDFs that returned 403 or an HTML page (Royal Society, Wiley, Springer, Canadian Science Publishing, IOP, journals.biologists.com) are recorded as such; open copies were taken from PubMed Central, Zenodo, Inter-Research or the Wayback Machine where they exist. Sources whose full text could not be obtained are cited as abstract-only in `sources.json`.
- Later batches (tags `fb-*`, `pmc-C-*`, `epmc-C-*`, `crq*`, `pmc-*`) were added for parts A (FishBase length-weight pages), the bridge (none: Genotype's file was read locally) and part C (powered flight in bats, insects and pterosaurs); same rules, same wrapper.
- Class Aves is the frozen holdout: bird rows of the one compiled table that contained them were dropped at parse time (`prior-art/raw/span-efficiency-table1-nonaves.json`) and no bird value was read into any file.
