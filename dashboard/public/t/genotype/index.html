The pectoral fin, the organ that matters for gliding

A flying fish's "wing" is an enlarged pectoral fin. Here is everything the proxy fish say about the pectoral fin (UBERON:0000151), by link type. "Expressed in" is detection, not causation. "Required for" is a loss-of-function phenotype in a single-gene zebrafish under standard conditions. "Sufficient for" is a verified gain-of-function allele that changes the fin.

Causal chains: gene to molecular function to process to tissue to phenotype

Each link carries its own source, organism, experiment type and an evidence grade. Grades, weakest to strongest: hypothesis, association (expression only), necessity (loss of function), sufficiency (gain of function), mechanism (a pathway step shown experimentally). A link with no fetched source is marked missing and named as a gap.
