## What this does and does not show

- Two repositories were under continuous commit for the same 24 hours, and the hour table shows when each was busiest. That is all a commit count shows: not participants, not results, not that either side read the other at a given hour (for that, see the `frontier-adapters` sessions in [`COLLABORATIONS.md`](../../COLLABORATIONS.md)).
- Subjects are quoted verbatim from their log; the theme lists are regex matches on the subject line, with the pattern shown, so inclusion is mechanical. A commit saying it preregistered something is not evidence that it did.
- Only the default branch is counted for both. Frontier has 220 more commits on other refs (worker branches); ours on other branches are not counted either.
