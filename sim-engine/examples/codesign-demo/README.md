The nearest candidate, kcnk5b, has chain strength *sufficiency*. 42 genes have chains (42 have at least one link graded necessity or better; 29 have a weakest link that strong), and all of it is zebrafish proxy data. Approving the edit fixes a shape, not a genotype.
- Guard rails held: an agent's direct `kind:"edit"` was refused, and so was a second decision on the same proposal.
