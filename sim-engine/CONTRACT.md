# sim-engine: the contract

Our own simulation backend for the Design Studio, spoken as an MCP server over stdio. **The tool
names and their JSON Schemas are the contract.** A collaborator's server that implements these names
and schemas can replace this one as a configuration change.

- Machine-readable schemas: **`contract.json`**, generated by `node sim-engine/server.mjs
  --dump-contract`. It is generated rather than hand-written so it cannot drift from the code. If
  this document and `contract.json` disagree, `contract.json` is right.
- Run the server: `node sim-engine/server.mjs`
- Tests: `node sim-engine/test/smoke.mjs` (add `--network` for the AlphaFold and ESMFold calls)

Dependencies live under `C:\Temp\sim-engine-deps\node_modules`, reached by a junction, because the
D: drive has about 2 GB free and `npm install` on it would be unwise.

## The envelope every tool returns

```json
{
  "result":     { "...": "tool-specific" },
  "provenance": [ { "quantity": "...", "value": 0, "kind": "...", "source": "..." } ],
  "scope":      "what this result does NOT establish",
  "weakest_input": "assumed",
  "counts": { "measured": 1, "assumed": 3 }
}
```

`scope` is mandatory and the envelope throws without it. A tool that cannot state its own limits is
not finished. `weakest_input` is surfaced so a caller does not have to read the whole provenance list
to learn that a result rests on a guess.

### `kind` is the whole point

| kind | meaning |
|---|---|
| `measured` | Read from a primary source that measured it in the stated organism. |
| `measured-secondhand` | A measurement, but quoted from a citing paper, review or summary rather than read in the source. Provisional. |
| `borrowed` | A real measurement, used for a molecule, tissue or stage it was **not** measured in. The borrowing is the assumption. |
| `derived` | Computed from other entries by a stated formula. No new empirical content. |
| `calibrated` | Set so the model reproduces one named wild-type observation. **A calibrated quantity can never be cited as a result.** |
| `assumed` | Not measured, not fetched. A placeholder. |

An unknown kind is rejected at runtime, so a typo cannot quietly downgrade a number into an
unlabelled one.

## Tools in v1

| name | what it does |
|---|---|
| `morphogen_diffusion` | Steady-state reaction–diffusion of one morphogen on a 2D or 3D fin-bud domain. Returns the field, λ = √(D/k), and the size of the region above a threshold. |
| `protein_structure` | AlphaFold DB model for a UniProt accession (mean pLDDT, metadata); with a missense variant, folds wild type and variant on Meta's public ESMFold and reports CA RMSD. |
| `physiology_chain` | Wraps `physiology/index.js` `createPhysiology`. |
| `growth_trajectory` | Wraps `development/trajectory.mjs`. |
| `lean_check` | Wraps `lean/eliminate/browser-check.mjs`. **Not a kernel check** — it evaluates the same formulas in floating point. |

Parameter lists are in `contract.json`; they are not duplicated here, for the drift reason above.

### Where the morphogen numbers come from

`params/zebrafish-morphogens.json`, fetched 2026-10-31, nothing from memory. Each entry carries its
URL, a quote, and whether it was read in the source or quoted at second hand.

- **D = 56 µm²/s** (fast fraction, 92 %), FCS on endogenous EGFP-tagged Fgf8a in a live zebrafish —
  `measured`.
- **half-life ≈ 9 min** → k = 1.283 × 10⁻³ s⁻¹ — `measured-secondhand`.
- **λ = √(D/k) ≈ 209 µm**, against an independently reported gradient length of ~200 µm. The 4.4 %
  agreement is checked in the smoke test and is the reason these two fetched numbers are trusted
  enough to use.
- **Shh has no measured zebrafish coefficient.** None was found. A Shh request borrows the Fgf8a
  value and is labelled `borrowed`; the engine never invents one.

Two cautions travel with these numbers and are repeated in every scope string: the measurements are
from the **gastrula**, not a 72 hpf fin bud, and a source–sink model is only one of two live
hypotheses for Fgf8 — hindered diffusion by heparan-sulfate binding is the other and is not
implemented.

## Validation

`PREREGISTRATION.md` states the first target, its criteria and its falsifier, and was written before
`validation/hhip-fin-area.mjs` existed. **The model failed it.** Run `node
sim-engine/validation/hhip-fin-area.mjs`; the exit code is non-zero because the criterion that
mattered failed.

In short: the measurement is D/V +50 % with A/P unchanged, and the model predicts the **opposite
axis** — all its expansion is anteroposterior, because a ZPA modelled as a posterior strip spanning
the bud's full height leaves no room to grow dorsoventrally. The failure, its diagnosis, and a
reasoning error in the pre-registration itself are written up in §5a of that file. Nothing was tuned
afterwards.

## Not in v1

- **`flight_sim`.** It would wrap the physics simulation's equations, which are not currently exposed
  as an importable module, and `physics/` belongs to another thread. Asked for through the hub rather
  than edited. A tool that cannot run is not listed, so `tools/list` does not advertise it.
- **Integrins and adhesion mechanics.** Out of scope by instruction. This is the natural module for
  the collaborator's MCP server to supply: adhesion, cell–matrix mechanics and the integrin
  signalling that would couple them to the morphogen field. Nothing here models force, contact or
  adhesion, and no tool should be read as if it did.
- **Whole-embryo all-atom simulation.** Not deferred but impossible: it is many orders of magnitude
  beyond any available GPU. "Molecular level" in this engine means molecular *species* and channel
  conductances in a cell-based tissue model, not atoms.

## Replacing this server with the collaborator's

Implement the names and schemas in `contract.json`, return the same envelope, and keep `kind`
honest. The one requirement that is not mechanical: a tool must not report a number as `measured`
that it did not read in a primary source for the organism in question. The envelope's value is
entirely in that discipline; a server that labels everything `measured` satisfies the schema and
destroys the contract.
