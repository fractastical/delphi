Things you should know:

- **Overridden verdict.** For `levin-2025-wisdom-05` my pre-registered rule mechanically returns "supports". With only two samples per group the test could not have returned anything else, so I recorded the rule's output but reported `inconclusive`. The caveats say this openly; my pre-registration should have required a minimum achievable FDR.
- **Not independent.** The nicotine, Girardia and barium tests rely on the claim's own source lab's data. The keratocyte test uses the primary study by a different lab, but it is the same experiment the review cites. Each caveat list notes this.
- **Rounded inputs.** The nicotine counts were rebuilt from rounded percentages, and Fisher's test treats embryos as independent although there were only 3 experiments. The effect size (about nine-fold) is more robust than the p-value.

What I could not do:

- **Computational fallbacks.** I did not run the two BioModels tests (`levin-2022-grn-learning-01` and `-14`) because five biological tests were done.
- **Paywalled supplement.** PubMed Central's supplement download requires a browser challenge, so I got the Sun et al. supplement from Elsevier's CDN instead.
- **Excel files.** The venv has no `openpyxl`, so I added small standard-library `xlsx.py` readers in two test directories.

Downloaded data is gitignored under each test's `data/` folder; only scripts, `derived/measured.json` and `result.json` were committed.
