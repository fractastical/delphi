## Notes

- Counts are API query results on the retrieval date; each distribution records the exact URL and the sha256 of the response.
- BOLD, MorphoSource and DANDI are searched by name. MorphoSource keyword search misses specimens catalogued under other names, so a gap there is not proof of absence. DANDI dandisets count only when their asset summary lists the taxon's NCBI id and an electrophysiological approach.
- FishBase/SeaLifeBase rows for each species are vendored in `files/lifebase/<slug>.json` (every row of the tables listed in the dataset record). Per-species summaries of all sources are in `files/profiles/<slug>.json` and `PROFILES.md`.
- No record carries an assessment; reliability scoring is a separate pass.
