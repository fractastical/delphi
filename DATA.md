# DELPHI data and biology index

Every data product in this repository, where it lives, and how it was made. Generated by the hub, 2026-10-31.
Large files are committed gzipped (`.json.gz`); read them with `zcat` or any gzip-aware JSON reader.
Proxy-species data (zebrafish, medaka) are never flying-fish data; every file says which organism each record comes from.

## Flying fish: anatomy, genes, pathways
| Path | What |
|---|---|
| `organism-design/examples/a-flying-fish.json` | Ontology blueprint for Exocoetidae: 536 Uberon/CL terms, body to cell, with the SPARQL queries |
| `anatomy-model/` (`build_fish.py`, `manifest.json`, `README.md`) | Blender 4.2 script for the segmented 3D fish; 110 named meshes mapped to ontology ids. Only the pectoral fin length (0.687 SL, Daane 2021) is evidence-backed |
| `dashboard/public/blueprint3d/model/flying-fish.glb` | The built 3D model (2.6 MB) |
| `genotype/map.vetted.slim.json` | Vetted genotype-phenotype map used by the viewer (proxy fish, by layer) |
| `genotype/map.vetted.json.gz` | Full vetted map, every link |
| `genotype/map.json.gz` | **UNVETTED** raw map, before deduplication, the standard-conditions filter and loss-of-function typing. Kept for audit only; do not use for results |
| `genotype/fin-subtree.json`, `fin-subtree.full.json.gz` | Pectoral fin below organ level from ZFA (40 terms, 10 cell-in-structure nodes, fin bud precursor) with gene links |
| `genotype/pathways.slim.json`, `pathways.json.gz` | Pathway membership for 3,857 of 4,571 genes (GO, Reactome v98 orthology-inferred, KEGG dre), evidence codes kept |
| `genotype/expression_index.json.gz` | Expression index used to build the map |
| `genotype/causal-chains.json`, `interactions.json`, `CAUSAL.md` | Gene to phenotype causal chains and tissue/cell interactions (being written by subagents; graded evidence, verbatim quotes) |
| `genotype/cache/daane2021_data_s1A_fin_measurements.csv`, `daane2021_fin_ratios.json` | Measured pectoral fin / standard length for 109 museum specimens (Daane et al. 2021 Data S1A) |
| `genotype/cache/calls*.json` | Every fetch the genotype thread and its subagents made |
| `genotype/nanopubs/unsigned/` | Unsigned nanopublication drafts |

## Formal layer (Lean 4)
| Path | What |
|---|---|
| `lean/Delphi/*.lean` | Theorems (population genetics, scaling laws, bending, blueprint certificate); 0 sorry |
| `lean/AUDIT-FLYING-FISH.md`, `flying-fish-audit.json` | Every theorem checked against the flying fish: 19 hold, 6 hypotheses violated, 67 cannot be evaluated (missing input named) |

## Claims, tests, open problems
| Path | What |
|---|---|
| `claim-tests/` | Pre-registered claim tests. Third-party datasets are NOT committed (licences and size, e.g. a 233 MB 1000 Genomes VCF); each `data/manifest.json` records the source URL and hash so they can be re-downloaded |
| `holdout/` | Frozen holdout (Aves) and its leak checker |
| `open-problems/` | 215 open problems, 80 candidate answers, their formal translations |
| `organisms/` | Taxa and datasets mentioned in the source books |
| `research/prior-art/` | Prior-art search, works and search log |
| `decisions/ideas.json` | Every adopted idea with its origin (researched, reach-synthesis, serendipitous) |
| `validation/` | MCP server test report; simulations checking the Lean results |

## Not in the repository, on purpose
- Full texts and PDFs of papers fetched during research (`physics/prior-art/raw/*.pdf|*.txt|*.html`, `genotype/cache/*fulltext*.xml`, the Daane supplement `.xlsx`): copyrighted; we keep metadata, quotes and the derived tables only.
- Third-party claim-test datasets (see manifests above).
