    Open a GitHub issue

    What sending does

    It opens a public issue on fractastical/delphi. GitHub asks you to sign in. The issue is a request that a person can turn into a pre-registered test.

    It does not add a taxon, resolve a name, download data, or run a test. A test is still written in test-data/claim-tests/ with its pass and fail criteria before any data is fetched.

    Class Aves is a frozen holdout exam. Filing a bird here does not open that exam.
